# Git Lesson 10 - Feature Branch

## What is a Feature Branch?

A feature branch is a separate branch used to develop a new feature without directly changing main.

## Workflow

1. Create a feature branch
2. Make changes
3. Commit changes
4. Push the branch
5. Create a Pull Request
6. Review
7. Merge into main
