# Git Lesson 01-Installation
## Goal
Install Git and creat the first local repository.
---
## Commands Learned
### Check Git Version
'''bash
Git --Version 
'''
Shows the installed Git version.
---
### Configure Username
'''bash
git config --global user.email "mehdi.behmanesh83@gmail.com"
'''
Sets the global Git email.
---
### Show Configuration
'''bash
git config --list
'''
Display current Git configuration.
---
## Notes
Git stores these settings globally and uses them for every commit.
