# Git Lesson 02 - First Repository

## 🎯 Goal

Create the first Git repository.

---

## What is a Repository?

A Repository is the home of your project.

Git stores the complete history of your project inside it.

---

## Initialize Repository

```bash
git init
```

Creates a new Git repository.

---

## Check Repository Status

```bash
git status
```

Shows the current state of the project.

---

## Notes

After running `git init`, Git creates a hidden folder named `.git`.

This folder stores all project history.

Never delete this folder.
