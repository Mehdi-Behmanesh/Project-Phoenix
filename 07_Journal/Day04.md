# Day 04

## 🎯 Today's Goal

یادگیری GitHub و اتصال Local Repository به Remote Repository.

## 📚 What I Learned

- Git روی سیستم من کار می‌کند.
- GitHub محل نگهداری Remote Repository است.
- `origin` نام Remote Repository من است.
- `git push` تغییرات Commit شده را به GitHub می‌فرستد.
- `git pull` تغییرات Remote را به Local می‌آورد.
- `main` شاخه اصلی پروژه من است.

## 🧠 My Understanding

امروز یاد گرفتم که Commit و Push یک کار نیستند.

Commit تغییرات را در تاریخچه Local ذخیره می‌کند،
اما Push آن Commitها را به GitHub می‌فرستد.

## 💡 Important Commands

```bash
git status
git add .
git commit -m "message"
git push
git pull
