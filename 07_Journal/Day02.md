## 📚 What I Learned

### Git
- یه ابزار کنترل ورژن پروژه است و روی سیستم ما نصب میشه

### GitHub
- رویاینترنت هست و میشه پروژه ها رو روی اینترنت داشته باشیم

### Local Repository
- محل ذخیره سازی فایل های پروژه روی سیستم خودم

### Remote Repository
- محل  ذخیره فایل های پروژه روی اینترنت یا سرور دیگر
